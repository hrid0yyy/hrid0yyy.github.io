  • Coding agent

    LiteAgent

    A coding agent built for smaller models running on a local machine. Current agentic systems carry very large system prompts and tool collections, which are heavy for small models and make them hallucinate; this one keeps both deliberately small, so a local model can handle the user's coding tasks without leaning on a cloud subscription.

    Python, LangGraph, local LLMs

    Peer-to-peer file sharing over a local network, built to be driven by agents through MCP. An agent discovers the other people on the network by itself and sends the files a prompt asks for, rather than someone doing it by hand. A WPF app covers the manual case.
